# Interactive prototype coverage

This is the traceability map for the states described in [the evolution method](prototype.md#método-de-evolução). Each capability is in one state only. Now's current state folder is `final-visual/`. `ux-prototype/` was deleted after the checks in Review status. `ui-prototype/` was skipped. The [interactive wireframe](../../../apps/web/references/interactive-wireframe.tsx) covers Later and Maybe. The folder name is the state. When a capability becomes Now, its part is removed from the wireframe. When it reaches the next state, the previous version is deleted. The priority names below are documentation references only. The application does not display those labels. Capability identifiers follow the [identifier mapping](../README.md#correspondência-de-identificadores) after transcription 3.

## Excluded capabilities

X01–X03 have no screens by design.

## Prototype limits

- Examples and dates are fictional and fixed. The reference date of `final-visual` is 27 October 2026, set in its data (`TODAY` in `index.html`).
- State stays in memory, except `final-visual`'s panel sizes, which are kept in `localStorage`. Refreshing restores the examples. Only the wireframe has a reset control; `final-visual` has none.
- The app has no backend, database, authentication, real file input, outbound request, mailbox access or external integration.
- A simulated submission always states that no document was sent.
- SVG diagrams in the wireframe encode geometry and interaction only. The wireframe has no presentation stylesheet or visual library.
- Demonstration calculations do not establish legal, procurement or accounting rules.

## Review status

`ux-prototype` was deleted after these checks. One item from the independent check (a plain click on a row after a comparison opens can be lost) was re-tested with agent-browser, using real clicks in 15 runs at one viewport size (1280×577), and was not reproduced. The Now rows above were checked against the code of `final-visual/index.html` and the PRD (issue #104). N13 is partly covered; the other Now rows are covered.

Checks run on `final-visual`: browser checks of the selection, comment, quote and assistant behaviour, and `bun run format:check`. Not verified: touch devices, Firefox, Safari, screen readers, and a real ⌘ key. This section does not claim a full review of every story.
