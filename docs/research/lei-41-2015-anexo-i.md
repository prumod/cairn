# Lei n.º 41/2015 annex I: categorias and subcategorias

**Research date:** 2026-11-03  
**Scope:** Official categorias and subcategorias listed in annex I of Lei n.º 41/2015 (the construction-activity regime), the amendments that changed annex I, a machine-readable source, and what the IMPIC public alvará lookup shows. Issue: prumod/cairn#159. Lookup and class values change over time; recheck before implementation.

## Finding

1. **Structure in force.** Annex I lists 5 categorias and 59 subcategorias. Each subcategoria has an ordinal number that restarts in each categoria. The list is in the table below. The annex does not assign a class to each subcategoria. The class is set per alvará under art. 6.º, n.º 2, which refers to «as classes respetivas aprovadas por portaria» ([DR, Lei 41/2015](https://diariodarepublica.pt/dr/detalhe/lei/41-2015-67377968)). The 5 categorias and 59 subcategorias are also stated by IMPIC (IMPIC title presentation, PDF; its web address was not recorded during the research, so this claim is unverified).
2. **Amendments after Lei n.º 25/2018.** The DR "Modificações" page lists one amendment to Lei n.º 41/2015, Lei n.º 25/2018, with the note «Alterado o anexo i» ([DR, Modificações](https://diariodarepublica.pt/dr/analise-juridica/modificacoes/lei/41-2015-67377968)). Lei n.º 25/2018 replaces annex I in full, with the qualifications column changed. I found no later law that amends annex I. Two later laws were checked (Lei n.º 3/2026 and Decreto-Lei n.º 97/2026) and neither refers to Lei n.º 41/2015 in its text. This is a partial check (see Unverified).
3. **Machine-readable source.** I found none from IMPIC or the DR. The official annex exists only as a rendered table in the original Diário da República PDF. The only open-data set found on dados.gov.pt is the 2017 "Alvarás Empreiteiro" set, last updated 2018. It was not inspected and is not a list of categorias and subcategorias.
4. **IMPIC lookup.** Yes. The lookup is searched by alvará, NIF/NIPC, name, postal code, locality, district, municipality and maximum class. Opening a result shows every subcategoria with its class, grouped by categoria ("HABILITAÇÕES"). The lookup does not show a per-subcategoria class in the result list. It is a web page with no export button observed ([IMPIC lookup](https://www.impic.pt/impic/pt-pt/consultar/empresas-titulares-de-alvara-de-empreiteiro-de-obras-publicas)).

## Amendments after Lei n.º 25/2018

- **Lei n.º 25/2018** (DR n.º 113/2018, Série I, 2018-06-14) is the only amendment to Lei n.º 41/2015 listed on the DR "Modificações" page ([DR, Modificações](https://diariodarepublica.pt/dr/analise-juridica/modificacoes/lei/41-2015-67377968)). Its art. 4.º says: «O anexo i da Lei n.º 41/2015, de 3 de junho, passa a ter a seguinte redação» ([DR, Lei 25/2018](https://diariodarepublica.pt/dr/detalhe/lei/25-2018-115501070)). The original text of the new annex is in [the DR PDF of Lei 25/2018](https://files.diariodarepublica.pt/1s/2018/06/11300/0251202517.pdf). The consolidated text labels annex I «em vigor a partir de: 2018-06-14» and the amendment «em vigor a partir de 2018-06-15» (consolidated 2018 text, a local copy, p. 27; its web address was not recorded, so this is unverified).
- **Observed in the 2018 annex text:** the categoria and subcategoria numbers and names match the 2015 annex. The qualifications column changed (for example, entries for «Agente técnico de arquitetura e engenharia (ATAE)» appear). One spelling differs: 5.ª, 3.ª reads «geotecnia» in 2018 and «geotécnica» in 2015. I read the 2018 headers from the text layer, not a visual comparison, and did not compare every qualification line.
- **Later laws checked, not annex I amendments:**
  - Lei n.º 3/2026 amends Lei n.º 31/2009 only. A text search of its articles found no reference to Lei n.º 41/2015 ([DR, Lei 3/2026](https://diariodarepublica.pt/dr/detalhe/lei/3-2026-996007054)). The IMPIC notice on it is at [IMPIC news](https://www.impic.pt/impic/pt-pt/noticias/alteracao-a-lei-n.o-312009-de-3-de-julho).
  - Decreto-Lei n.º 97/2026 (2026-05-20) concerns housing and tax measures. A text search of the DR page found no reference to Lei n.º 41/2015 ([DR, Decreto-Lei 97/2026](https://diariodarepublica.pt/dr/detalhe/decreto-lei/97-2026-1124493227)). IMPIC's notice on the same decree returned a server error when I tried to read it.
- **Not an amendment to annex I:** Portaria n.º 212/2022, de 23/08, updates the class values ([IMPIC news](https://www.impic.pt/impic/pt-pt/noticias/portaria-n.o-2122022-de-23-de-agosto-procede-a-atualizacao-dos-valores-das-classes-dos-alvaras)). Class values are set by portaria, per the art. 6.º, n.º 2 wording above. This does not change the categorias or subcategorias.

## IMPIC alvará lookup

- **Where:** IMPIC, Consultar, Construção, «Alvarás de empreiteiro de obras públicas» ([IMPIC lookup](https://www.impic.pt/impic/pt-pt/consultar/empresas-titulares-de-alvara-de-empreiteiro-de-obras-publicas)).
- **Search fields:** Nº Alvará, NIF/NIPC, Denominação, Código Postal, Localidade, Distrito, Concelho, and Classe Máxima (a select from 1 to 9). I found no subcategoria filter.
- **Result list (observed):** for each match, the alvará number (for example «5 - PUB»), NIF/NIPC, Denominação and Morada.
- **Detail view (observed, one search result opened):** Alvará, Data de inscrição, Classe Máxima, NIF/NIPC, Denominação, Morada, Concelho, Distrito, País, and a table titled «HABILITAÇÕES» with «Descrição» and «Classe». The table lists the 59 subcategorias grouped under «1ª Categoria» to «5ª Categoria», with one class value per subcategoria. The detail view also shows telephone and e-mail fields. These are not recorded here.
- **Answer to question 4:** yes. The lookup shows a company's subcategorias and class for each. It is reached by opening a result. Lookup data comes from a server call (observed as a POST to `/impic/ajax/call/impic_api/consultar/ajax/43`), not from a downloadable file.
- **Not verified:** whether the detail view covers every alvará, and whether it shows an alvará that has expired or been cancelled.
